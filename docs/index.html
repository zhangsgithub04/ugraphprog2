How this works

For every unordered pair, u toggles adjacency when the degrees match; u+ only adds missing edges between equal-degree vertices; u− only removes existing edges between equal-degree vertices. All degrees are computed from the current graph before any edge changes, so each step is simultaneous. Different-degree pairs are unchanged.

Both u+ and u− always stabilize on finite graphs. Each changing step adds or removes at least one edge; there are at most n(n−1)/2 possible edges. A u+ stable graph has each degree class forming a clique. A u− stable graph has different degrees at the endpoints of every edge. A graph is u+ complete exactly when its u+ stable outcome is Kₙ, and u− collapsible exactly when its u− stable outcome is n isolated vertices. Stable outcomes need not be complete or empty. These two graph properties are calculated independently of the map’s active rule.

The map contains one state per graph isomorphism class: 1, 2, 4, 11, 34, 156, and 1,044 states for n = 1 through 7. Each point is an entire unlabeled graph; the inspector shows a canonical representative and its individual vertices. For u, equality, cycles, and transient distances are measured up to isomorphism; a period-1 state can change its labeled adjacency while retaining the same structure. Each step applies the rule then identifies the isomorphism class; displayed vertex numbers need not track the same vertex across steps. Every basin contains one attractor cycle; for u+ and u− this is a single stable graph with a self-loop (period 1). Layers use exact steps to the attractor. All n! vertex permutations are used to construct exact isomorphism classes, not degree-sequence approximations. Counts and basin sizes are unweighted class counts. Internal labeled enumeration is limited to n ≤ 7 (2,097,152 labeled graphs reduced to 1,044 classes). Computation runs in a background worker.
